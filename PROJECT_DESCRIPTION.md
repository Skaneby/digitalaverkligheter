# Project Description: Digitala Verkligheter (v2)

## Overview
This project is a modern reimagining of [digitalaverkligheter.se](https://www.digitalaverkligheter.se). The goal is to create a premium, responsive web application that reflects the original site's mission: exploring the intersection of humanity and digital technology.

## Technologies
- **Framework**: React with Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS (presumed based on class names in `App.tsx` like `bg-background-dark`, `text-slate-100`)
- **Icons**: Material Symbols / Icons
- **AI Integration**: Gemini (via `@google/genai`) for potential translation or content generation.

## Goals
1.  **Recreate Content**: Port the original blog posts, "About Me" section, and core philosophy ("Finns tekniken för vår skull?").
2.  **Premium Design**: Use glassmorphism (`glass-header`), smooth animations (`animate-in`), and a sophisticated dark mode palette.
3.  **Responsiveness**: Ensure the site looks great on all devices.
4.  **Project Tracking**: Keep this file updated with development progress.
